3 · Ask

The API key in config.js is not a secret here, and cannot be: anything a browser sends is readable by whoever holds the browser. It stays because it is what attaches this API to a usage plan, and the usage plan's 100 requests/day is the cap on what a runaway page can spend. In a real deployment the key would live behind a server that holds it on the user's behalf — which is the same argument ADR-0001 makes for the BFF.
